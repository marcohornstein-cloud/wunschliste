# Wunschliste und Sparkonto

Eine einzelne Webseite (`index.html`), die ohne Server, ohne Konto und ohne Internet läuft:

- Wunschliste mit gleichmäßiger Verteilung des Spaßgelds und Termin-Check
- Einkommen eintragen, automatische Aufteilung auf Hauptkonto, Sparkonto und Spaßkonto
- Sparkonto-Rechner: Was wird aus meinem Ersparten in 1 bis 50 Jahren?
- Willkommen-Tour, die das System Schritt für Schritt erklärt

Alle Eingaben bleiben im eigenen Browser (localStorage) und werden nirgends hochgeladen.
Das ist eine Rechnung, keine Anlageberatung.
